# Mots-clés SEO — positionnement Xavier Adda

Angle central : **le client a un PROJET et un besoin métier, pas une techno.**
La techno (Next.js, Symfony…) est un front secondaire pour clients avertis. Le cœur = projet / résultat / métier.

Basé sur tes services (site vitrine, e-commerce, app sur-mesure, IA, SEO, refonte, maintenance), IDF & remote.

---

## 1. Intention "projet / résultat" (tech-agnostique) — LE CŒUR
Ce que tape une PME/indépendant qui veut un site :
- créer un site internet pour mon entreprise
- faire un site internet professionnel
- créer un site vitrine
- créer une boutique en ligne / vendre en ligne
- site internet pour prendre des rendez-vous
- combien coûte un site internet (déjà couvert par ton blog)
- j'ai un projet de site, par où commencer (déjà couvert)
- créer une application / un outil en ligne

## 2. Par métier — LA GROSSE OPPORTUNITÉ (1 page par métier)
Stratégie établie chez les concurrents, souvent en template cheap → battable en qualité.
Cible tes verticales prioritaires :
- création site internet artisan (plombier, électricien, menuisier, maçon…)
- création site internet restaurant
- création site internet coach / thérapeute
- création site internet avocat / profession libérale
- création site internet agent immobilier
- création site internet PME / TPE
→ Chaque page : besoins spécifiques du métier + exemples + prix + CTA. Pas de contenu dupliqué entre pages.

## 3. Situation / douleur (fort intent, peu travaillé)
- refaire mon site internet / refonte site web
- mon site n'est pas visible sur Google
- mon site est trop lent
- moderniser mon site internet
- mon site n'est plus maintenu (→ ton article maintenance)

## 4. Local — Google Business + long-tail (PAS le head term)
Head local ("freelance web Paris") = dominé par annuaires (Malt, Codeur, Collective), imbattable en direct.
Jouable :
- création site internet [ville IDF] (Versailles, Boulogne, Nanterre, ta ville…)
- création site internet artisan [ville] (métier + ville = long-tail en or)
- + fiche Google Business complète (en cours)

## 5. Ton angle différenciateur (à glisser partout)
- création site internet SEO inclus
- site web optimisé référencement / rapide sur mobile
- freelance en direct, sans agence (alternative agence web)

## 6. Top-funnel / blog (attirer en amont — ta stratégie qui marche)
- prix création site 2026 · wordpress ou nextjs · audit SEO gratuit
- site vitrine ecommerce ou application · comment budgéter un site
- site non maintenu risques · SEO IA (être cité par ChatGPT)
Hook contenu utile : **France Num — chèque de 500€** pour la digitalisation des TPE/PME.

## 7. Techno de niche — SECONDAIRE (clients avertis, TJM haut)
Petit volume mais qualifié, conversion forte vs agence :
- développeur Next.js / React freelance
- développeur Symfony / Laravel freelance
- développeur freelance SaaS / MVP
- intégration IA / chatbot site web

---

## Constats du marché (recherches web 2026)
- 88% des acheteurs cherchent un prestataire en ligne avant de contacter ; 62% évitent une entreprise sans site.
- 84% des TPE/PME françaises ont déjà un site → concurrence réelle, mais **angle refonte** porteur.
- "Next.js" = terme de recruteur, pas de client PME → garder en front secondaire.
- Head terms locaux = annuaires imbattables → gagner par contenu + métier + Google Business.

## Plan d'action priorisé
1. **Pages par métier** (2-3 verticales pour commencer : artisan, restaurant, + la tienne). Le meilleur ROI.
2. **Blog top-funnel** : continuer, mailler vers pages métier/services.
3. **Google Business + 1-2 pages ville** pour le local.
4. **Valider les volumes** : Google Keyword Planner (gratuit) + onglet Performances Search Console une fois indexé.

Note : liste = hypothèse de départ, à confirmer avec un outil de volume et tes données Search Console réelles.
